# LUMEX — 거래소 앱 실행/로딩 애니메이션 웹 클론

거래소 앱 화면 녹화를 프레임 단위로 분석해서 실행 흐름과 애니메이션을 웹(HTML/CSS/JS)으로 재현한 연습 프로젝트입니다.
원본 브랜드(로고, 이름, 거래소 코인, 마스코트)는 모두 가상의 **LUMEX** 브랜드로 교체했습니다.

빌드 과정이나 의존성은 없습니다. `index.html`을 브라우저에서 열면 됩니다.

```bash
npx serve .            # 또는 python3 -m http.server
```

- 데스크톱: 휴대폰 프레임 안에서 실행됩니다. 아래쪽 **↺ 다시 실행** 버튼으로 처음부터 다시 볼 수 있습니다.
- 모바일: 화면 전체를 씁니다.
- `index.html?splash`: 런처를 건너뛰고 스플래시부터 시작합니다.
- `index.html?app`: 애니메이션 없이 바로 홈 화면을 띄웁니다.

## 재현한 애니메이션

| 구간 | 원본에서 관찰한 내용 | 구현 |
| --- | --- | --- |
| 앱 실행 | 홈 화면 아이콘이 커지면서 앱 창이 열림 | 아이콘 위치에서 화면 전체까지 `clip-path`와 크기를 애니메이션 (480ms) |
| 하얀 스플래시 | 흰 배경에 로고 (약 1.3초) | `.splash`, 상태바 글자는 검은색 |
| 검은 화면 전환 | 회색을 거쳐 어두운 배경으로 빠르게 페이드 | `background-color` 220ms 전환 |
| Face ID | 다이내믹 아일랜드가 정사각형으로 커짐 → 초록 링이 3D로 회전 → 원으로 정리 → 체크 표시가 그려짐 → 블러와 함께 사라지고 알약 모양으로 돌아감 | 스프링 이징을 쓴 아일랜드 크기 변경, 타원 3개의 `scaleX` 회전, 체크는 `stroke-dashoffset`으로 그림 |
| 홈 노출 | Face ID 링이 도는 동안 스플래시 뒤로 홈이 나타남 | 스캔 중에 앱을 보여주고 스플래시를 페이드아웃 |
| 탭 전환 | 활성 탭 아이콘의 선이 그려지고 노란 포인트가 튀어나옴, Trade 아이콘은 회전 | `pathLength=1` + `stroke-dashoffset`, 스프링 `scale` |
| 첫 진입 로딩 | Markets는 스켈레톤 카드가 먼저 뜨고 이어서 콘텐츠가 페이드인, Convert는 `--`로 시작했다가 코인이 채워짐 | 시머 스켈레톤 → `reveal` 애니메이션 |
| 당겨서 새로고침 | 당긴 거리만큼 로고가 커짐 → 놓으면 5개의 점으로 갈라짐 → 점들이 회전하며 모임 → 하나의 다이아몬드로 합쳐짐 → 작아지며 사라지고 화면이 제자리로 돌아감 | 고무줄 저항(rubber-band) 드래그 + Web Animations API 시퀀스. 모든 화면에서 동작 (터치/마우스 드래그) |
| 기타 | 검색창 문구가 위로 롤링, 프로모션 캐러셀, Exchange/Wallet 세그먼트 슬라이드, 탭 밑줄 슬라이드, 하단에 붙는 Discover 바, 실시간 시세/호가창 깜빡임, 자산 탭 좌우 스와이프 | 모두 구현 |

## 파일

- `index.html`: 런처, 스플래시, 5개 탭(Home / Markets / Trade / Futures / Assets) 마크업
- `styles.css`: 디자인 토큰과 레이아웃, 키프레임
- `app.js`: 실행 시퀀스, 탭 라우팅, 새로고침 제스처와 애니메이션, 가짜 실시간 데이터
